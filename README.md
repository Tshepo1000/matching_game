# Matching Game

A C# Windows Forms memory game. Players flip cards to find matching pairs of icons, and a timer tracks how quickly they respond.

## Features

- Grid of hidden icons to match in pairs
- Timer to measure the player's response time
- Built as a Visual Studio Windows Forms project

## Getting started

Prerequisites: Windows with Visual Studio (2019 or newer) and the .NET desktop development workload.

```bash
git clone https://github.com/Tshepo1000/matching_game.git
```

1. Open `MatchingGame.sln` in Visual Studio.
2. Press **F5** to build and run.

## Tech stack

C#, .NET, Windows Forms.
